# TripBanBan v0.4 Scope

## User flow

1. Launch / language preference
2. My Trips
3. Create or select trip
4. Trip home
5. Shared fund / expenses / records
6. Settlement
7. Trip report / PDF share
8. Settings / language / data & backup

## Included in architecture alpha

- My Trips list with active/upcoming/settled groupings
- Create Trip form and account-plan member limit check
- Quick trip switcher from every trip header
- Traditional Chinese, Simplified Chinese, English ARB resources
- System-locale preference
- Account-level Free / Full / Pro / Business entitlements
- `.tripbanban` ZIP backup schema v1
- Single-trip export/import with duplicate-as-copy safety
- Full account export entitlement
- Basic CSV export
- Portable IDs for cross-device data restoration
- Supabase v0.4 schema draft

## Still functional-alpha work

- Persistent local database repository
- Supabase auth/sync/realtime
- IAP purchase verification
- Receipt file inclusion in backup
- Automatic cloud backup / version history (future Pro)
- Custom amount / ratio split editor
